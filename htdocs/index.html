🛠️ Stack Technique

  • Backend : C++ 20 (httplib)
  • Base de données : SQLite 3
  • Frontend : HTML5 / CSS3 / Vanilla JS

⚙️ Architecture

Architecture hybride avec mise à jour des cours en RAM (mutex-protected) et persistance des transactions via SQLite. Système de sessions sécurisé par cookies.

Développé avec passion sur Arch Linux.
